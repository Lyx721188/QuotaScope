## 已实现

- 设置隐藏时保留 HWND、WinUI 宿主及导航外壳，卸载页面控件，释放统计快照。关闭或离开统计页使旧扫描结果失效；扫描运行状态单独保留，快速重开不会重叠启动扫描。
- 统计扫描支持主动取消，以及关闭窗口、离页、关闭读取时取消。进度显示来源和实际读取计数；取消刷新保留旧完整结果。手动刷新重新检查文件变化，筛选复用快照。目录、读取块和各类记录循环设置取消检查点；被取消的结果不发布、不写入该来源的半成品缓存。普通后台读取不受影响。
- Claude Code / Codex JSONL 逐行读取。Codex 追加记录复用持久化累计计数和模型状态，先验证整个旧前缀；改写、截断、未换行的末行及没有续读状态的旧缓存全量重扫。扫描期间追加的内容留待下一轮，已经读取的边界若发生变化会重新校验；不把读取失败的半成品当成有效缓存。
- 面板隐藏时释放 DirectComposition/Direct2D 绘图缓冲，恢复显示时重建。悬停卡隐藏一分钟后释放缓冲；静止时使用 250 ms 时钟，交互与动画恢复 30 ms 时钟。
- 补齐原生窗口、托盘图标、临时事件句柄和图标构建失败路径的释放。字体格式缓存最多保留 128 项。单实例互斥量仍按应用生命周期保留。
- 账本缓存过期后清空旧时间戳，使新扫描获得新的五分钟有效期；闲时维护回收过期派生缓存，不等待正在扫描的锁。刷新线程在空闲时最多等待一分钟，命令仍立即唤醒。
- 设置 → 存储与诊断显示指定统计缓存的大小/文件数，支持清理和禁用/16/64/256 MiB 磁盘预算，默认 64 MiB。启动与保存缓存时淘汰旧文件；写入使用临时文件替换，超大单文件不保存。清理同时失效内存账本；账户、密钥、原始日志、最后读取结果和价目表保留。
- 导出本地诊断 JSON，记录白名单中的版本、资源、部分设置计数、当时扫描/更新状态与缓存大小。报告不读取缓存正文、密钥、账户地址或会话文本。固定文件替换上一份报告，导出失败保留旧报告；目录/链接不作为清理对象。
- 设置 → 关于提供手动检查、默认关闭的每日自动检查、跳过指定版本及更新页面入口。检查时间跨重启保存；安装由用户在发布页面选择，不自动下载或重启。

## 大文件扫描对比

本节是流式读取构建的前后测量，未将后来存储与诊断构建的结果混入性能对比。

改动前保存调试程序为 `windows/target/debug/quotascope-stream-before.exe`，
SHA-256 为 `7504A05C95ABE546DA1F9EC48B02ACF20304FB110A85B5E974E2B6AC130F35D0`。
流式调试构建 SHA-256 为 `FA224EFD173F20DC442573105FD590E3BEBBC99E4E88136B56EEA7C3878ADF5A`。
各次运行使用独立应用配置、用户目录、模拟会话及新鲜本地价目缓存，不读取真实
账号，不下载价目。模拟日志 68,800,061 字节、40 万条重复累计计数，追加时包含
新计数、重复计数和模型切换。第一次先旧后新，第二次先新后旧；另运行两次新构建
并重启进程，验证磁盘缓存续读。第四次还逐阶段读取磁盘缓存，独立核对累计计数。

| 测量 | 改动前（两次） | 流式读取（四次） |
| --- | --- | --- |
| 完整扫描的私有内存增量峰值 | 132.26、133.69 MiB | 7.31、7.69、4.68、4.11 MiB |
| 完整扫描至 UI 完成 | 4.744、6.981 秒 | 4.521、4.540、6.681、8.742 秒 |
| 追加后刷新至 UI 完成 | 4.914、6.586 秒 | 0.449、0.466、0.570、0.940 秒 |
| 重启后再追加，至 UI 完成 | 未作旧构建重启测量 | 0.339、0.961 秒，总量均为 600 Token |

内存增量是扫描期间采样的最高 `PrivateMemorySize64` 减去扫描前值，包含 UI、
价目与汇总分配，不是整个应用内存，也不是硬性内存上限。名义采样间隔 20 ms，
UI 查询约每 200 ms 一次，实际间隔受 UI Automation 调用影响，可能漏掉短峰值。
数据只代表本机调试构建的有限模拟场景；没有声称所有日志的完整扫描都会变快。
读取内存仍取决于最大单行、Claude 去重集合、汇总和价目表；旧前缀摘要不是安全签名。

## 空闲资源观察

对长空闲测试的独立空账户进程用 `Get-Process` 每 15 秒采样，共 33 个点，记录
`PrivateMemorySize64`、`WorkingSet64` 与 `HandleCount`，见
`windows/target/resource-idle-samples.json`。关闭设置后的稳定观察段有 19 个点，
私有内存约 154.18–154.41 MiB，句柄 2685–2695，未观察到持续递增。宿主首次
加载的内存仍保留，关闭页面不等同于卸载整个 WinUI。此记录只证明这个有限空闲
场景的观察结果，没有做前后版本对照，也不能据此排除真实账户或所有交互中的泄漏。

## 未量化的部分

扫描的私有内存增量已按上面的模拟场景测量；未量化真实账号下整个应用的长期内存
节约。窗口回归使用空账户配置，统计页使用隔离的模拟记录；未对多个真实账户、
显卡设备重置或全部 DPI 场景作长期验收。
取消是协作式的：正在执行的系统 I/O、单条 JSON 解析、锁等待或价目请求不能直接
抢占；价目请求现有超时为 20 秒。设置宿主和导航外壳仍保留，未通过私有 WinUI
清理函数或强制裁剪工作集回收。
