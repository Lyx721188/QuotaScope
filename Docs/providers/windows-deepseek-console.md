# Windows DeepSeek 官网会话

本功能用 DeepSeek 官网登录会话读取账户余额。它与 API Key 的余额读取相互独立：
官网会话可在没有 API Key 时提供余额；仅有 API Key 不能建立官网会话。

## 配置

1. 在 Edge、Chrome、Brave 或 Vivaldi 中打开 `https://platform.deepseek.com`，登录需要读取的账户。
2. 打开 QuotaScope 设置 → 账户，搜索 DeepSeek，点击配置。API Key 可独立填写，用于 API 余额。
3. 点击“从浏览器导入”。导入后台读取目标网站的 `userToken`，Default profile 优先，然后查看有界数量的命名 profile。它不会把浏览器所有 localStorage 复制进 QuotaScope。
4. 启用 DeepSeek 并刷新，余额按官网会话读取。
5. 附加账户先按现有流程添加自己的 API Key，再在“用量概览”中该账户的卡片导入官网会话。导入前在浏览器登录对应账户；每个账户保存独立会话。

导入只说明本地凭据已找到并加密保存，余额请求成功才表示账户数据已读取。设置中“清除官网会话”仅清除所选账户的官网凭据，保留 API Key。移除附加账户会清除该账户的 Key、官网会话和相关设置。

## 刷新与错误

- API Key 余额成功时优先采用 API；指定的拒绝、不可达、服务错误或不可读回复可由成功的官网余额接替。限流不切换路由，官网失败时保留原 Key 错误。
- 只有 HTTP 401 或官网明确认证过期码会触发一次续读。403、重定向和限流不会触发登录态替换。
- 主账户续读可以使用当前浏览器中的不同 token。续读前确认加密槽仍是原 token，防止恢复已清除或已替换的会话。附加账户不会自动借用主账户或当前浏览器会话，需显式重新导入。
- 本机只保存 DPAPI 加密凭据，不保存官网原始账户正文或 API Key 跟踪身份。

## 当前验证边界

上游参考固定为 Pulse `3696a65`。合成协议、余额回退、账户隔离和本地 HTTP 分类已测试；独立 WinUI profile 使用合成 Edge 数据验证了导入、删除、主/附加账户清除和真实 Windows DPAPI 文件。

这些检查不等于真实 DeepSeek 账户已验收。真实账户与 Release 交互的验收状态分别记录在[发布验收](../release-acceptance-2026-10-04.md)中。
