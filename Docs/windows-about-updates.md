# 关于页的可选更新检查

参考 [Pulse 1.7.2 的静默探测](https://github.com/qunqin24/Pulse/blob/b570dd77fa3dd9c7ce779812eedff1db8738aaf1/Sources/Pulse/App/AppUpdate.swift)，Windows 保留默认关闭的自动检查设置。

开启自动检查后，应用每天检查一次，打开关于页时也静默检查。关于页复用当前进程五分钟内的检查结果，包括失败结果；离页或关闭重开不会立即重复请求。只有磁盘中的上次尝试时间、尚无本进程结果时，仍允许关于页读取答案。正在进行的检查不会重叠启动。

关闭自动检查后，打开关于页不会发请求。“检查更新”按钮始终支持主动重试，不受五分钟缓存或自动开关限制。每日检查可提醒新版本；关于页探测不会弹出升级通知。下载、安装和重启由用户选择。

请求只读取 QuotaScope 的公开 GitHub release 元数据，使用应用设置中的代理，不携带账户凭据、不跟随重定向，超时 20 秒、响应最多 2 MiB。仅正式 Windows 标签及已上传的 Windows ZIP 符合候选条件；失败显示“检查更新失败”，不显示“已是最新版”。

验证：三项触发规则回归、整仓 824 passed / 6 ignored、fmt、普通 Clippy（233 项已有诊断，无新增）及隔离 Debug UI 已通过。UI 使用空账户与拒绝连接的本机代理，覆盖默认关闭、开启探测、已保存当日尝试时间、失败提示、近期结果复用、关闭重开和关闭开关后的手动重试。脚本为 `windows/quotascope-win/tests/about_updates_ui_smoke.ps1`。实际 portable Release CI 待独立核对；这项验收不证明外网当前可达或已有用户安装版已升级。
